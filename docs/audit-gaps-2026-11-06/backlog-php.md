### symfony
- **SY1 Twig leftovers** (SI 12 `TwigAssetsTagMissing`, SI 13 root HTML in extending template and `enum()`/`enum_cases()` class missing). Reuse `twig-missing-asset` logic for `{% javascripts %}`/`{% stylesheets %}`; root-content check needs block nesting and `{# #}`/verbatim masking, fire only when `{% extends %}` is a literal on the first tag; enum check only for project classes whose file declares `enum`. - **SY2 PHP practice and deprecation checks** (SI 10 the 13 constructor/controller practice checks, SI 15 form checks, SI 22 `$defaultName`/`registerCommands`/invokable return value, SI 24 `HttpFoundationPropertyWrite`, `HttpKernelEventArgument`, `ConstraintViolationListFindByCodes`). Name matching after `use` resolution, gated by class role (`extends AbstractController`, `#[AsCommand]`, `implements Twig\Extension`) and composer version gate like `reached()` in `php_checks.rs`; hints, not warnings, for style advice (own setting under `commandChecks`/`deprecationChecks` or new `practiceChecks`). - **SY3 Container reference checks** (SI 4 unknown `%param%`, SI 5 `class:` without a PHP class, SI 6 deprecated class from PHP).

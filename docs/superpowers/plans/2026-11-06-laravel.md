# Laravel (`aritti.laravel`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** An OpenIDEA plugin pair that gives Laravel projects Blade highlighting, completion and go-to-definition for routes, views, config, translations, env keys, middleware and components, missing-reference warnings, a routes tool window and artisan commands.

**Architecture:** Text-index plugin in the style of `plugins/symfony` (`index.rs` scans project files, `refs.rs` recognises string-literal call sites, `lib.rs` wires providers). Blade is a separate data-plus-syntax-provider language plugin in the style of `plugins/twig`, so it can be installed alone. No PHP semantic model exists in the API (see `LIMITATIONS.md`, Symfony section), so every feature is a text pattern keyed on function/method names.

**Tech stack:** Rust (edition 2024, `wasm32-wasip2`), `openidea-plugin` SDK `v0.1.37` (match `plugins/symfony/Cargo.toml`), own empty `[workspace]` per plugin.

Its jars were never downloaded.

The Marketplace also lists the free **"Laravel" plugin (id 7532, `de.espend.idea.laravel`) by Daniel Espendiller, MIT, public source** (`Haehnchen/idea-php-laravel-plugin`, same author as the Symfony plugin already ported here). So the path is a **hybrid**:

- **Source port** of the MIT plugin at tag `0.15.4` (commit `3a07f4a5f67dc0aacbcd6fdb11a8b5c9814803b0`) for the features it has: routes, controllers, views, config, translations, assets, Blade layout markers. `LICENSE` ships in the package, the author is credited, and the revision is recorded in `change-notes`.
- **Features from Laravel's own documentation** for the rest (env keys, middleware, route groups, JSON translations, problems, tool window, artisan commands).
- Names: `aritti.laravel` (display name `Laravel`) and `aritti.blade`. Nothing refers to the proprietary plugin.

## Scope

**In (maps to API as shown):**

| Feature (behaviour spec) | OpenIDEA mechanism |
|---|---|
| Blade highlighting, `@directive` tags, `{{ }}`/`{!! !!}`, comments, folding, structure (sections, components) | `aritti.blade`: `languages/blade.toml` + `syntax-provider` |
| `route('name')`, `to_route`, `redirect()->route` completion + go to definition | `completion`, `definition`; index of `->name('x')` in `routes/*.php` and resource/`Route::resource` derived names |
| `view('a.b')`, `View::make`, `@include`, `@extends`, `<x-…>` completion + definition | index of `resources/views/**/*.blade.php`, components in `app/View/Components` and `resources/views/components` |
| `config('a.b')` keys | index of arrays returned from `config/*.php` |
| `__('x')`, `trans`, `@lang` | index of `lang/**` (PHP arrays and JSON) |
| `env('X')` | `.env`, `.env.example` |
| `middleware('alias')`, `can('ability')` | alias map from `bootstrap/app.php` / `app/Http/Kernel.php`; `Gate::define` and policy method names |
| Validation rule strings (`'required\|email'`) | static rule list + custom rules in `app/Rules` |
| Eloquent column names in `where('col')`, `$fillable`, `$casts`, `->col` | columns parsed from `database/migrations/*.php` `Schema::create` / `table` calls, model→table by naming convention + `$table` |
| Missing view/route/config/translation warnings | `publish_diagnostics` on `file-opened`/`file-saved` |
| Gutter: controller action ↔ route, view ↔ controller, component class ↔ view | `line-markers` |
| Routes tool window (method, URI, name, action) | `[[contributes.views]]` `Tree`, built from the index (no `artisan route:list`, works without PHP) |
| `artisan` commands: `route:list`, `cache:clear`, `config:clear`, `migrate`, `make:*` | commands + `process:php` (optional); `make:*` runs artisan so file creation works |

**Out (no API; list in `LIMITATIONS.md`):** class/type-aware resolution (`$user->` members, facades, container `app('x')` types), refactors and rename, Find Usages, hover docs, live inspection while typing, creating files from quick fixes, clipboard-paste actions, live templates, Livewire/Inertia wire-property typing, database schema tooling from a live connection. Each is either a missing API or a missing provider kind; append to the matching `LIMITATIONS.md` section rather than inventing workarounds.

## Review Focus (write these as tests first)

- `route('users.show')` matches only the call sites listed above, not `$collection->route('x')`-style lookalikes inside comments or strings. `refs_ignores_comments_and_unrelated_calls`.
- Half-typed PHP and Blade (`route('`, `@if(`, `<x-`) cut at every byte offset never panics. `survives_every_prefix`.
- Multi-line fluent chains: `Route::get(...)\n->name('a')` and `Route::prefix('api')->name('v1.')->group(...)` produce `v1.a`. `route_names_include_group_prefixes`.
- Non-ASCII source: UTF-8 byte offsets (syntax provider) vs UTF-16 columns (editor API) agree. `columns_are_utf16`.
- `find_files` skips dot-dirs and gitignored paths on the real host but not in `MockHost`; read known paths with `read_file` (`.env`, `bootstrap/app.php`), glob only `routes/`, `config/`, `resources/`, `database/`. A missing file is `Error::Invalid` on the real host, not `NotFound`.
- Index respects the 30 ms provider budget on a 2k-file project; rebuild on `file-saved` instead of per request.

- Request only capabilities the code uses.
- Comments explain why only; each deliberate ceiling gets a `ponytail:` comment naming the limit and the upgrade path.

## Risks, ranked

1. **Spike A (Blade file association).** Decides Task 1 and a large share of the value. Do first.
2. **Text-only accuracy.** Method-name matching gives false positives on lookalike calls. Mitigation: restrict to facade/helper/chain shapes from the call-site list; accept the ceiling, document it.
3. **50 ms editor budget** on big projects. Mitigation: index on save, serve providers from memory, cap results.
4. **Clean-room drift.** Never open the paid plugin's UI strings or assets while writing ours; spec comes from Laravel's docs, not from observing the paid plugin.
